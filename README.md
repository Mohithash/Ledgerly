# Ledgerly

**Know where it goes.** A bring‑your‑own‑key AI expense tracker.

- 📷 **Receipt → expense** — snap a receipt (or type “uber to airport 32”); AI extracts merchant, date, total, category and line items. You confirm before saving.
- 🍩 **Overview** — spent vs budget with pace projection, category donut, cumulative‑spend chart against the budget line.
- 🧾 **Transactions** — searchable, grouped by day, month navigation.
- 🎯 **Category budgets** — per‑category limits with wavy progress bars.
- 🔎 **Monthly insight** — headline, biggest shift vs last month, anomalies, three concrete savings tips.
- Any currency symbol; no accounts, no bank links, no cloud.

BYOK: Claude (Anthropic) or any OpenAI‑compatible endpoint. See [PRIVACY.md](PRIVACY.md).
